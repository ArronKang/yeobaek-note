# 여백 노트

PDF 리더 + 손글씨 노트 + 이 앱에서만 열리는 인터랙티브 문제지(`.ybq`) 웹앱.
갤럭시 탭 + S Pen 기준으로 만들었어요. 한 번 열면 오프라인에서도 동작해요.

## 설치 (갤럭시 탭)
1. 크롬으로 GitHub Pages 주소를 열기
2. ⋮ 메뉴 → **앱 설치** (또는 홈 화면에 추가)

## .ybq 문제지
JSON 파일. `problems` 안에 `choice` · `short` · `passage` 문항.
수식은 `$...$`, 굵게 `**...**`, 밑줄 `__...__`.
문제나 답칸을 **꾹 누르면** 정답과 풀이가 떠올라요.
