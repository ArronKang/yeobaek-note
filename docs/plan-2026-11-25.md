# 캔버스 댓글 반영 계획 (2026-11-25)

디자인 캔버스(https://claude.ai/artifact/2uTvVHd1LvYwzsWb1o88Ge)에 사용자가 남긴 댓글 52개와 직접 그린 보드 2장을 위치별로 정리하고, 네이티브 앱(`android/`)에 바로 옮기는 계획이에요.

**공통 규칙 (사용자 지시)**
- 리소스(아이콘, 색, 부품 모양, 그림)는 직접 지어내지 않는다. 지금 쓰는 Apple 공식 iOS 27 UI 키트 값과 SF Symbols(키트 안 SF Pro 글꼴), 사용자가 준 원본 그림만 쓴다.
- 펜 고르기 막대는 사용자가 준 iPadOS 도구 막대 그림을 작은 디테일까지 그대로 따른다(개인 소장용 앱).
- 아티팩트로 보여 주지 않고 앱에 바로 넣고, 단계마다 커밋하고 푸시한다.

## 1. 위쪽 구성 (사용자 보드 "원하는 위에 구성")
| 위치 | 지시 | 할 일 |
|---|---|---|
| 큰 캡슐 왼쪽 위 "탭" | 탭이 맨 위 캡슐 안에 | 탭 줄 = 캡슐 첫 줄 |
| "파일모드 등 / 그리기 모드" | 모드 전환 | 캡슐 안 세그먼트(그리기 / 파일) |
| 오른쪽 도구 막대 그림 | 그리기 모드 = 펜 고르기 막대 | 그리기 모드에서 막대 표시 |
| 아래 화살표 글 | 파일 모드: 오답 문제만 추출, 전체 채점, 파일 전체 초기화, 오답만 진하게 보기, 답 보기, 해설 | 파일 모드 줄에 이 버튼들 |
| "연필종류(떼어낼 수 있게)" | 펜 부분은 떼어낼 수 있게 | 7번 창 댓글의 자석 동작 |

## 2. 펜 고르기 막대 (7 필기, 원본 비교, 필기(공식 키트), 도구 막대)
| 위치 | 지시 |
|---|---|
| 막대 전체 | 원본 그림 그대로, 작은 디테일도 놓치지 말 것 |
| 펜 | 윤택(광택)이 없음 → 원통 광택 |
| 펜 | 숫자(80, 80, 50)가 펜에 있어야 함 |
| 펜 끝 | 팁 끝이 각짐 → 끝을 둥글게 |
| 형광펜 | 형광펜과 플라스틱 부분 간격이 원본과 다름, 각짐, 부드럽지 않음 |
| 색 | 전체적으로 눈 아픈 색 → 원본처럼 부드러운 색 |
| 펜 | 양쪽 원근(음영)이 대칭 |
| 모든 모서리 | 완전히 뾰족한 곳 없이 아주 미세한 곡률 |
| 연필 | 원본은 육각 → 면이 보이게 |
| 막대 | 위쪽 탭과 하나로 붙어 있고, 떼려 하면 자석처럼 버티다 떨어져 떠 있음. 화면 가장자리에 가져가면 자석처럼 붙음. 다시 위로 붙이기 가능 |
| 펜 줄 | 왼쪽으로 끌어당기면 고무줄처럼 게이지가 차고 +가 커지며 "펜 추가하기"가 서서히 보임. 다 찬 상태에서 놓으면 펜 추가 창 |
| 펜 | 펜마다 종류, 색, 굵기, 투명도를 따로 저장 |
| 펜 | 다양한 펜 종류 |
| 더보기(⋯) | 자 빼기/넣기, 펜 개수, 민감도, 필기 보정, 손가락으로 그리기 등 필기 옵션 |
| 옵션 | 자를 옵션에서 고를 수 있게 |

## 3. 펜 굵기와 색 창 (8 펜 굵기와 색)
| 위치 | 지시 |
|---|---|
| 탭 | 탭을 닫는 × |
| 탭 아래 제목 | 지움(탭에 이미 제목) |
| 창 전체 | 펜 종류, 색, 굵기, 투명도를 펜마다 따로 저장 |
| 굵기 줄 | 퍼센트로 조절, 굵기를 실시간으로 보여 줌 |
| 굵기 줄 | 천천히 움직이면 미세 조정(눈금이 확대된 돋보기 팝업, iOS 글자 꾹 누를 때 돋보기처럼), 빠르면 평소대로 |
| 투명도 막대 | 실제 리퀴드 글래스처럼(손잡이를 잡으면 유리 렌즈처럼) |
| 색 줄 | 사용자 맞춤, 최근 쓴 색이 뜸(모든 펜 색 설정 자리 공통). 처음 배치는 지금 그대로 |

## 6. 문제지 (문제지 정답 카드, 사용자 보드 Artboard 1)
| 위치 | 지시 |
|---|---|
| 해설 글 | 해설이 길어도 글자가 UI를 넘지 않게 |
| 맞았어요/틀렸어요 | 가운데 "애매 🔺" 추가. 버튼 위가 아니어도 꾹 누른 채 어느 방향으로든 조금 움직이면 그 방향 버튼이 눌린 상태, 떼면 선택. 버튼 위로 가져가는 방식도 유지 |
| 틀렸어요 | 빨간색 |
| 보기 ③ | 틀린 문제를 자동으로 모아 서재에 [오답] 탭, 동기화 |

## 9. 글꼴 (필기(공식 키트))
- 앱으로 빌드할 때 글꼴이 깨지지 않게: SF Pro(아이콘 SF Symbols 포함)와 Pretendard를 앱 안에 넣는다. SF Pro 파일은 공개 저장소에 올리지 않으므로 `.gitignore`에 넣고, 없으면 기존 아이콘으로 돌아가게.

## 개발 순서
1. 바탕: SF Pro/SF Symbols 글꼴, Apple 키트 색과 글자 토큰, 기호 목록
2. 위쪽 캡슐: 탭(×) + 모드 전환 + 펜 고르기 막대(원본 그림 그대로) + 페이지 눈금, 제목 줄 삭제
3. 펜: 펜마다 따로 저장, 펜 종류 추가, 펜 추가 고무줄, 펜 창(퍼센트 굵기, 미세 조정 돋보기, 유리 손잡이, 최근 색, 사용자 색)
4. 더보기: 페이지 보기 방식, 다크/라이트 전환 아이콘, 필기 옵션(자, 펜 개수, 민감도, 보정, 손가락)
5. 막대 떼어내기(자석), 가장자리 붙이기
6. 문제지: 카드 3버튼(애매, 빨간 틀림), 방향 밀어 고르기, 긴 해설 스크롤, 오답 모음 탭
7. 서재: 단순한 설정 아이콘, 폴더 아이콘 바꾸기와 꾹 눌러 순서, 오답 섹션, 검색 순서, 선택 모드 옵션, 새 노트(표지, 더보기, 사용자 색), 자동 표지
8. 설정 이름, 진동 삭제, 투명도 퍼센트, 눈금 켜고 끄기
9. 원본 PDF 문제지(.ybq 2: 원본 PDF + 답안 정보 층) 앱 지원과 변환 스킬
