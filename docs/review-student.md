## 1. 학생으로 써 본 흐름과 느낌

> 나는 고2. 친구가 "PDF에 바로 필기되고 문제지 채점도 되는 앱"이라며 링크를 줬다. 크롬에서 설치하고 처음 켰다.

1. **첫 화면** — "노트 / 아직 노트가 없어요". 깔끔하다. 그런데 친구가 말한 "문제지"가 안 보인다. 세로 화면이라 왼쪽 메뉴가 숨어 있고, ☰를 눌러야 문제지·최근·검색이 나온다. ☰가 메뉴인 줄은 알지만 **문제지가 있다는 걸 모른 채** 노트만 만들 뻔했다.
2. **새 노트** — + 를 누르니 창이 뜬다. 제목에 "새 노트 1"이 흐리게 있어서 그냥 만들어도 된다는 게 보인다. 표지 색, 양식 미리보기가 실제 모양이라 고르기 쉽다. 좋다.
3. **필기** — 펜이 바로 써진다. 위의 펜들 중 하나를 누르면 쑥 올라와서 뭘 골랐는지 보인다. 같은 펜을 한 번 더 누르면 굵기·색 창이 나온다(처음엔 몰랐다. 우연히 알았다).
4. **위쪽 아이콘들** — 글자 없이 아이콘만 있어서 깔끔하지만, 홈 탭의 네모 아이콘 네 개(사이드바, 새 페이지, 템플릿…)는 **뭔지 누르기 전엔 모른다.** 누르면 바로 실행돼서 "이게 뭐지?" 하고 확인할 방법이 없다.
5. **삽입 탭** — 이미지 넣기를 눌렀더니 "준비 중이에요". 도형, 링크, PDF 페이지 추가도 전부 같다. **누를 수 있게 생겼는데 안 되는 버튼이 4개**라 앱이 미완성처럼 느껴진다.
6. **페이지 추가** — 맨 아래에서 더 당기니 고무줄처럼 늘어나며 틀이 나오고, 놓으니 새 페이지가 생겼다. 손맛이 좋다. 다만 **처음 쓰는 사람은 이걸 모른다.** 아래로 내려도 아무 표시가 없어서 "페이지는 어떻게 늘리지?" 하고 헤맨다.
7. **문제지** — 보기를 톡 누르면 골라지고, 그 위에 풀이를 써도 된다. 꾹 누르니 정답 카드가 떴다. 채점 동그라미가 도장처럼 찍히는 게 재밌다. 하지만 꾹 누르면 정답이 나온다는 것도 **알려 주는 것이 없다.**
8. **PDF** — 학교 프린트 PDF를 가져와서 필기했다. 형광펜이 글자 줄에 딱 맞아서 놀랐다. 그런데 서재로 나왔다 다시 들어가려니 **PDF가 서재 어디에도 없다.** 다시 파일을 찾아서 열어야 한다. 필기는 남아 있지만 매번 파일을 고르는 게 번거롭다.
9. **정리** — 노트를 길게 눌러 여러 개 고르려 했는데 **선택이 안 된다**(눌렀다 떼면 바로 풀림). 폴더는 만들어졌다.
10. **검색** — 세로 화면에선 검색칸도 ☰ 안에 숨어 있어서 바로 못 찾는다.
11. **다크 모드** — 깊은 숯색이라 눈이 편하다. 문제지·노트 종이도 같이 어두워진다. PDF는 원본 그대로 하얗다(당연하지만 밤에는 눈부심).

**한 줄 평**: 필기·채점·고무줄처럼 손에 닿는 부분은 좋다. 그러나 **처음 쓰는 사람이 기능을 발견할 길**과 **PDF를 다시 여는 흐름**이 약하고, 안 되는 버튼과 선택 버그가 신뢰를 깎는다.

## 3. 조사 (원인)

- **P1**: `pdf.js`의 `Y.openPdfFile`은 PDF를 메모리에만 열고, 필기만 `yeobaek.v2.p.<파일명:크기>`에 저장. 서재 목록(`Y.lib.notes`)에 PDF 항목이 없음. PDF 원본은 수 MB라 `localStorage`(5~10MB)에 못 넣음 → IndexedDB가 필요.
- **P2**: `library.js`의 `bindItem` — 0.5초 뒤 선택 모드로 바꾸며 `renderBody()`로 목록을 **다시 그림**. 손을 뗄 때의 클릭은 새로 그려진 같은 항목에 떨어지고, 새 항목은 길게 누른 표시(`_lp`)가 없어 "선택 해제"로 처리됨.
- **P3**: 820px 미만에서 `#side`가 드로어로 바뀜(`@media (max-width:819px)`). 패드 세로가 정확히 이 구간. 첫 보기 `L.view = 'all'`은 노트만 거름(`kind !== 'quiz'`).
- **P4**: `editor.js` 삽입 탭이 `later` 함수(토스트)를 4개 버튼에 연결.
- **P5**: 버튼에 `aria-label`은 있지만 터치에서는 보이지 않음. 마우스 툴팁도 없음.
- **P6**: 고무줄은 끝을 넘어 당겨야만 보임. 문제지 꾹 누르기는 안내를 지운 뒤로 단서 없음 (설명 글은 금지라는 원칙과 충돌).
- **P7**: `engine.js` 상수 `LILAC = '#B9A9FF'`, 검색 사각형 `rgba(185,169,255,.38)`.
- **P8**: `core.js` 아이콘 `importf`가 아래 화살표.

## 4. 개선 방안

| # | 방안 | 원칙과의 관계 |
|---|---|---|
| P1 | PDF를 가져오면 원본을 **IndexedDB에 저장**하고 서재에 PDF 항목(첫 쪽 그림이 표지)을 만든다. 누르면 바로 열림. 같은 파일을 다시 가져오면 같은 항목으로 연결(필기 유지). `navigator.storage.persist()` 요청 | 사용자가 처음부터 원한 "PDF 리더" |
| P2 | 길게 누른 직후 짧은 시간 안의 클릭은 무시 (`L.lpAt`). 목록이 다시 그려져도 선택 유지 | 버그 |
| P3 | 세로(820px 미만)에서는 서재 제목 아래에 **보기 바**(노트 / 문제지 / PDF / 최근 / 즐겨찾기)를 가로로 두고, 머리에 **검색 아이콘**을 둔다. 검색 아이콘을 누르면 제목 자리가 검색칸으로 바뀜. 첫 화면은 **최근**(노트·문제지·PDF 모두, 최근 순) | 숨은 기능 없애기, 글자 최소 |
| P4 | 안 되는 버튼은 숨김. 삽입 탭에 남는 것이 텍스트 하나라서 **삽입 탭 자체를 없애고** 탭은 홈 / 필기 / 보기 셋 | "안 되는 건 보이지 않게" |
| P5 | 아이콘 버튼을 **꾹 누르면 이름표가 말풍선처럼** 위에 떠오르고, 그때 손을 떼면 실행하지 않음 (iOS의 길게 눌러 미리보기와 같은 결). 평소엔 글자 없음 | 아이콘만 원칙 유지 + 발견 가능 |
| P6 | 글 대신 **물리적인 단서**: ① 노트 맨 아래에 처음 닿으면 고무줄 틀이 살짝 딸려 나왔다 들어감(한 번만, 서랍 손잡이가 보이듯) ② 문제지를 처음 열면 첫 보기 하나가 살짝 눌렸다 올라옴(누를 수 있다는 신호). 각 1회만 | 설명 금지 + 실생활 은유 |
| P7 | 올가미·검색 색을 강조색 `--acc`로 통일 | 색 일관성 |
| P8 | 가져오기 아이콘을 "상자로 들어가는 화살표"로 | 오해 방지 |
| P9 | 표지 안 제목은 유지(공책 이름표), 아래 이름은 그대로. 대신 PDF 표지는 첫 쪽 그림 | 보류(사용자 판단) |
| P10 | 다크 모드에서 PDF 밝기를 살짝 낮춤 (`filter: brightness(.88)`) — 반전은 그림이 망가져서 안 함 | 눈부심 완화 |
| P11 | `a.download` 속성 + 공유 시트 경로 확인. 실제 사이트에서 이름 확인 | 확인 |

## 5. 만들 모습 (구체 명세)

### 서재
- 세로: `[☰] 최근                 [🔍][≡][↕][⤓][+]`  
  그 아래 보기 바: `노트  문제지  PDF  최근  즐겨찾기` (고른 것만 진한 글자 + 강조색 점, 좌우로 밀 수 있음)
- 가로: 지금처럼 왼쪽 사이드바, 사이드바에 **PDF** 항목 추가
- 첫 실행 기본 보기: 최근
- 🔍를 누르면 제목 자리가 검색칸으로 펼쳐지고(왼쪽에서 늘어남), 비우고 바깥을 누르면 다시 제목으로
- PDF 항목: 표지는 첫 쪽 축소 그림, 오른쪽 위 작은 PDF 표시, 아래 이름·날짜

### 편집 화면
- 탭: 홈 · 필기 · 보기 (삽입 없음)
- 모든 아이콘 버튼: 0.45초 꾹 누르면 위에 이름표 말풍선(유리, 짧은 감속 곡선으로 떠오름), 뗄 때 실행 안 함
- 노트 맨 아래 첫 도달 시 고무줄 틀이 32px 딸려 나왔다 용수철로 들어감 (기기당 1회, `yeobaek.v6.pullhint`)
- 문제지 첫 열기 시 첫 문항의 첫 보기가 눌렸다 올라옴 (1회, `yeobaek.v6.taphint`)
- 올가미 점선, 선택 상자, 검색 표시는 강조색

### 저장
- IndexedDB `yeobaek` / 저장소 `blobs` (키: PDF id) — PDF 원본
- 서재 항목 `{ id, kind: 'pdf', title, key, thumb, pageCount, ... }`
- 필기는 지금처럼 `yeobaek.v2.p.<key>`
