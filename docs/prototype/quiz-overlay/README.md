# 문제지 새 구조 시제품 (2026-11-23)

원본 PDF는 그대로 두고, 그 위에 보이지 않는 답안 정보 층(quiz.json)을 얹는 방식의 시제품이에요. `yeobaek-quiz.html`을 브라우저로 열면 바로 동작해요.

## 확정한 메커니즘
- 펜은 언제나 그냥 필기예요. 쓰는 동안 문제지 판정은 없어요.
- **문제 번호 꾹** (번호 칸 안, 약 1.5mm 안에서 0.5초, 0.15초부터 고리): 찍힌 점을 지우고 보기 ①~⑤ 칸 위 필기를 읽어 채점 → 빨간 펜 ○/✕ + 정답·해설 카드
  - 기호를 감싸는 동그라미, 덮어 칠함, ✓ = 선택 / 가로지르는 사선, ✕ = 지운 보기 / 조금 스침 = 무시
  - 선택이 하나면 바로 채점, 0개거나 2개 이상이면 카드에서 직접 고르기
- **✓ 버튼**: 그 쪽 전체 채점, 애매한 문제는 "?"
- 히트박스는 "누르는 칸"이 아니라 "읽는 칸" (번호 칸만 꾹을 받음)
- 좌표는 전부 PDF 페이지 비율 좌표, 필기와 같은 변환을 써서 확대·축소해도 어긋나지 않음
- .ybq = zip(original.pdf + quiz.json: 문제마다 쪽, 번호 칸, 보기 칸, 종류, 정답, 해설)

검토하며 빠진 방식과 이유, 지표 비교는 대화 기록 기준으로 정리했어요(연구 근거: Li 외 CHI 2005 펜 모드 전환 실험에서 "펜을 가만히 대고 기다리기"는 가장 느리고 오류가 많아서, 꾹은 문제당 한 번만 쓰도록 함).

## 파일
| 파일 | 역할 |
|---|---|
| `make_page.py` | 문제지 한 쪽을 그림(`page.png`)으로 그리고 번호·보기 위치(`quiz.json`)를 뽑음 |
| `template.html` | 시제품 화면 (`__PAGE__`, `__QUIZ__` 자리에 그림과 quiz.json을 넣음) |
| `yeobaek-quiz.html` | 위 둘을 합친 완성본 |

다시 만들기: `python make_page.py .` 후 template에 page.png(base64)와 quiz.json을 넣어 yeobaek-quiz.html 생성.

## 다음 순서
1. 설계 문서(quiz.json 형식, 좌표 규칙, 읽기 규칙) 2. 앱: PDF 보기 위 번호 꾹 + 표시 층 3. 앱: 필기 읽기, ✓ 채점 4. 변환(PC 스킬 자동 초안) 5. 앱: 칸·정답 편집 모드
